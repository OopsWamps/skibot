# 09 — 多机位真值验收报告（相位与参考带前的门）

Status: ready-for-agent
Blocked by: 05 — MotionBERT 单目提升接入；06 — 多机位标定与三角化工具；08 — 多机位实拍采集

## What to build

单目三维管线对三角化真值的验收：逐帧角度误差（within-athlete、按相机方位角分层）、跨机位一致性、物理一致性。给出通过/不通过结论与适用包络。这是相位与参考带之前唯一的门。

## Acceptance criteria

- [ ] 六项指标的误差表：中位、p90，按方位角分层
- [ ] 跨机位一致性：同一趟两个方位角，相位中位数差 ≤3°
- [ ] 物理一致性四项：骨长恒定、脚不穿雪面、关节不反折、遮挡处曲线不跳变
- [ ] 明确写出适用包络（坡度、机位距离、分辨率、光照）
- [ ] 通过/不通过结论与依据完整
- [ ] 不通过时指出是模型、标定、同步还是真值本身的问题

## Notes

验收线：关节角中位 ≤5°、p90 ≤10°。参考量级：OpenCap 4.5°、Pose2Sim <4°、Fasel 2017 <4.9°。来源规格：`.scratch/phase-2/spec.md`（验证与采集）。
