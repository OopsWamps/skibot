# 08 — 多机位实拍采集

Status: ready-for-agent
Blocked by: 01 — 冻结三维指标定义与改写决策记录；06 — 多机位标定与三角化工具；07 — 文献锚点验收

## What to build

按规格的采集协议完成一次实拍：3 机位、拍手同步、标定、硬软雪各一组、两坡度两速度、日常雪服；对部分帧做人工标注。这是三维真值的唯一来源，也是关键路径上的人力环节。

## Acceptance criteria

- [ ] 每段满足同步判据（同一相机两次拍手偏移差 ≤ 半帧），不满足的段落被丢弃并记录
- [ ] 每段任一时刻每个身体段至少被两台相机看到，否则重录
- [ ] 采集前后各有一组标定，相机在采集期间未移动（移动则重新标定）
- [ ] 记录坡度角与参考点的测量方法
- [ ] 原始素材、标定文件、同步结果与标注文件落盘并登记
- [ ] 条件矩阵（坡度、方位、距离、雪况、速度档）可追溯到规格
- [ ] 样本量的确定依据（按目标置信区间反推）有记录

## Notes

3 台相机起，每台与滑行方向成 30~45° 前侧、髋部高度；60~120fps，锁曝光/对焦/白平衡，关防抖。来源规格：`.scratch/phase-2/spec.md`（验证与采集）。
