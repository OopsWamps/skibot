# 16 — 报告页改选人物

Status: ready-for-agent
Blocked by: None — can start immediately

## What to build

分析完成后在报告页改选被分析的人。候选来自已落盘的全部人物轨迹，展示带编号的候选骨架预览；改选后只重跑评估与渲染，不重跑姿态。

## Acceptance criteria

- [ ] 候选列表来自全部人物轨迹，不是只有自动选中的那一个
- [ ] 预览带编号，能对应到人物
- [ ] 改选后不重跑姿态检测
- [ ] 报告与标注视频同步更新
- [ ] 单人素材不出多余候选
