# 11 — 相位切分人工标注验收（相位条上线前的门）

Status: ready-for-agent
Blocked by: 05 — MotionBERT 单目提升接入；10 — 三维相位切分与逐弯置信度

## What to build

选 10 段覆盖单人侧面、跟拍混合、犁式小弯、卡宾的素材，逐弯标注换刃与弯顶点，与自动切分对比，产出边界误差与相位帧错分率报告，给出通过/不通过。

## Acceptance criteria

- [ ] 覆盖四种素材形态，合计约 100 个弯
- [ ] 换刃时刻误差中位 ≤0.25s、p90 ≤0.5s
- [ ] 每段弯数误差 ≤1
- [ ] 相位帧错分率 ≤10%
- [ ] 未达标时给出排查结论（信号、阈值还是素材形态）
- [ ] 标注文件与对比脚本可复现
