## What to build

报告按相位出指标：侧面三项按入弯/控制/出弯，正面两项维持全程。数据不足的相位为 null 并带原因。advanced 三维带由通过验证的管线跑 EPFL 生成，过渡期报告并列二维与三维两列。

## Acceptance criteria

- [ ] 每个指标条目含 phases，每个相位有中位数、落带率、带内百分位、有效帧数、判断
- [ ] 数据不足的相位为 null 并带原因，不填 0、不静默消失
- [ ] advanced 带按相位生成，误差上界写入口径，带宽不窄于误差区间
- [ ] novice/intermediate 标注"未校准、二维口径外推"
- [ ] 报告写明参考系（体固/重力/坡面）、零点、符号
- [ ] 过渡期二维/三维双列并注明来源
