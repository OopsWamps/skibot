# 07 — 文献锚点验收（实拍前门）

Status: resolved
Blocked by: 04 — JCS 六项三维指标；05 — MotionBERT 单目提升接入

## What to build

用教练级素材跑三维管线，比较弯末的髋、膝与内侧膝角度和 Bon et al. 2021 的均值 ±2SD。给出通过/不通过结论，不通过则回炉定义或管线。这是实地拍摄前的门。

## Acceptance criteria

- [x] 弯末时刻的识别方法与相位切分定义一致
- [x] 髋、膝、内侧膝三项与文献值的对比表，含均值、SD 与判定
- [x] 结论明确写出通过或不通过；不通过时给出排查结论
- [x] 素材与运行参数表可复现（素材目录、person、fps、帧数、权重、阈值）
- [x] 结果写入验证报告（docs/lit_anchor_validation.md）

## Answer

**判定：不通过**（弯末与 apex 两种采样、剔除污染弯前后方向一致）。弯末
外膝/内膝/外髋未落入 Bon et al. 2021 平行式（PT）的 ±2SD；排查为阴性——
定义、公式、内外侧映射、弯末帧语义与 Bon 数值引用全部核对无误（含 MDPI
原文 Table 1 逐项核对、左右转归属由原文力值列独立证实），未发现管线定
义 bug。

完整对比表、运行参数与排查细节：`docs/lit_anchor_validation.md`；逐弯数
值：`datasets/recreational_ski/lit_anchor_turns.json`；执行脚本：
`scripts/lit_anchor.py`（可复现）。

## Comments

### 2026-10-26 文献口径核验（实施前）

- Bon et al. 2021 = IJERPH 18(6):3029（MDPI/PMC 双源）。9 名男性滑雪教练、
  20° 坡、SL 板、Xsens MVN Link 17-IMU 240Hz；弯末 = 重心最低点、外板卸压
  前；180°=伸直；SD 为弯级变异（n=90 弯/弯型）。**PT/ST = 平行式/短转弯
  两种技术**——本票 Notes 与 DECISIONS 里 "141.5/148.7°（PT/ST）" 的旧解
  释（两种测量法）是误读，实为 PT 下左/右转弯两组，已在 DECISIONS #9 修正。
- 六组 mean/SD：外膝左/右转 141.46±3.70 / 148.74±3.46，内膝
  115.69±6.23 / 117.49±5.50，外髋 164.99±4.71 / 166.20±2.53。原文未写髋角
  的三点定义（只说 "hip flexion"，Xsens 骨盆-大腿关节角），docs 里"肩-髋-
  膝（髋）"是仓库推断，髋格判定对口径敏感，报告已标注。
- 交叉文献：Berg 1995（精英 GS 膝 66–114°，180=伸直）、Alhammoud 2020
  （国家队 GS 内腿最小 64°）、Yoneyama 2000（膝屈曲 30–80°，0=伸直，注意
  换算）、Zorko 2015（斯洛文尼亚示范队，Grood-Suntay）——均已分人群记录。

### 2026-10-26 执行与验证记录

- 素材：SkiiCat 教练示范三段（`results_channel/` 的 BV1js4y137Mr 全幅鹤弯
  person00/1190帧30fps、BV1LM41137hm 标枪弯 person05/1232帧25fps、
  BV19T411h7Ub 半幅鹤弯 person02/1510帧30fps）——本机最接近"教练级"的素
  材，但都是练习动作不是平行弯。
- 执行链：`scripts/lit_anchor.py`（`load_kp` → `MotionBERTLifter().lift` →
  `segment_phases` → 每弯弯末（end_frame−1）与 apex（peak_frame）双采样外
  膝/内膝/外髋三点夹角 → 按弯向对照 BON_PT mean±2SD）。解剖护栏：采样点
  任一三点角 <40°（物理不可能）的弯整弯剔除并计数。逐弯 JSON 落盘。
- 结果：右转三格不通过（外膝 −49.2°、内膝 −21.1°、外髋 −56.2°），左转有
  效弯 n=2 不足判定；apex 同向；剔除 6 个污染弯后仍 5/6 格不通过。**总体
  不通过，且对采样定义、污染剔除、输入变体稳健。**
- 排查阴性项：内外侧映射（侧倾符号 → 弯向 → 外/内腿）逐环核对；冠状前
  倾"向左倾为正"符号契约补了测试（此前只有 ==0 断言）；弯末帧语义、conf
  门槛同源性、2D 夹角几何、Bon 值引用与方向映射——四路独立对抗复核均未
  驳倒。
- **执行中修掉的真缺陷**：`skibot/skeleton.py` 的 trc 别名表只有 12 个映
  射（TODO_VALIDATE 悬置），肘/腕/头顶/颈/髋中/十个脚点在真实 trc 里存在
  却被丢成 NaN——MotionBERT 的 17 个输入通道有 4 个恒为零。已按真实表头
  （22 marker）补全并加测试（`tests/test_trc.py`）。修复后模型输入解剖完
  整；锚点数值随之移动（鹤弯素材上冠状侧倾幅值变小，检出弯 12→5），判定
  方向不变。
- 单目深度不确定性量化：稳定帧三维角 vs 同帧 2D 投影角差 14~21°（膝），
  超 Bon ±2SD（±3.5~6.2°）数倍；x-y 投影一致性检查（相对位移误差为身高
  2~5%）证明模型还原了输入图像平面，偏差来自深度先验而非输入错误。这正是
  spec 把多机位真值（issue 08/09）排在文献锚点之后要量化的量。
- **回炉路径**（写进验证报告）：①换真正的平行弯示范素材（archive.txt 登
  记的 BV1644y1o72G / BV1qM4y187hr / BV1yk4y177rL，需重下）；②先经
  issue 08/09 量化深度误差，再决定单目门是否可过或改多机位口径执行。
- **遗留（需睿君确认）**：本门用辅助三点夹角作验收口径，与 ADR-0001 §6
  "辅助量不参与判断" 的冻结条款冲突（六项 JCS 主指标与动捕文献不可直接
  比），待确认后补一行 ADR 修订（DECISIONS 二期决策 #8）。
