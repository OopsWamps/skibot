# 18 — 前后对比报告

Status: ready-for-agent
Blocked by: 09 — 多机位真值验收报告；12 — 相位化报告与三维参考带

## What to build

同一用户两次上传按相位对比，给出差值与方向。每一项单独判可比性，不可比项显示"无对比数据"并说明原因。相机与坡度差异写入假设说明。

## Acceptance criteria

- [ ] 对比按相位给出差值与方向，不做逐弯匹配
- [ ] 每项单独判可比，不可比项显示原因
- [ ] 不同水平档、不同视角的组合都有明确行为
- [ ] 相机与坡度差异写入假设说明
- [ ] 对比页能从历史任务中选择两次分析
