# 04 — JCS 六项三维指标

Status: ready-for-agent
Blocked by: 01 — 冻结三维指标定义与改写决策记录；02 — 指标注册表整改；03 — 三维骨架契约与提升适配器

## What to build

在三维骨架上实现六项 JCS 指标与三点夹角辅助量。评估流程同时产出二维与三维两套结果；视角门控取消，视角分类只进质量统计；二维报告作为回归对照保持不变。

## Acceptance criteria

- [ ] 合成直立骨架的六项结果符合定义（伸直、零倾角等边界值）
- [ ] 合成屈曲骨架的结果随角度单调变化
- [ ] 报告每项带基准标识与三点夹角辅助量
- [ ] 二维指标在相同输入下逐值不变（除新增字段）
- [ ] 视角门控取消后所有帧参与计算，视角只进质量统计
- [ ] 缺数据帧在六项上均为空值，不产生 0 值
