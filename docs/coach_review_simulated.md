## 1. 评审范围与方法

- 任务说明提供的五指标定义、advanced 档参考值（EPFL Ski2DPose 世界杯竞技者
  p25~p75，2026-10-20 批准）、3 段大众素材实测（2 位自报中级爱好者 + 1 位教练示范，
  2026-10-21）、EPFL 竞技者膝弯全程中位约 122°、docs/DECISIONS.md 第 4~7 条。
- PSIA、CSIA 与国内中文教学体系（郝世花等）对各水平动作特征的公开定性描述。

把握度分三档：高（教学体系共识或几何事实）；中（动作原理推断）；
低（数值无公开文献依据，仅供参考）。

## 2. novice/intermediate 逐项评审

### 2.1 档位方向判断（高把握）

五项指标随水平单调移动：屈髋、膝弯角度随水平变小（novice > intermediate >
advanced）；躯干前倾随水平变大；正面膝角随水平变小；肩髋对齐角度随水平变小
（初学者上体带转是公认错误，水平越高上体越方正）。advanced 档现行值：屈髋
[66,135]、膝弯 [97,153]、前倾 [22,49]、正面膝角 [94,153]、肩髋对齐 [4,15]。

### 2.3 单调性与相容性核查

- 若按建议值填入，五项在 novice → intermediate → advanced 上全部单调：
  屈髋中点 160 → 136 → 100；膝弯 164 → 146 → 125；前倾 6 → 16 → 35；
  正面膝角 153 → 139 → 123；肩髋对齐 21 → 13 → 9。档间保留重叠（同一滑行者
  一个弯内膝角可摆动 25~40°，无重叠的带会把正常相位波动判成跨档）。
  （主会话复核 2026-10-21：现行占位值同样满足单调性与带间重叠。）
- EPFL 膝弯全程中位 122° 略低于 advanced 带中点 125°，因该带含换弯相位，自洽。
- 大众素材爱好者段的屈髋中位（154~171）、膝弯中位（152~158）、前倾中位（4~8）
  分别落入上述 novice 带内或带沿；教练示范段对 advanced 带落带率更高，与示范者
  姿态更接近高阶带一致。这组实测支持建议值的方向。
- 自报"中级"的爱好者实测姿态落在 novice 带内，提示自报水平与实测姿态存在系统性
  偏移。报告建议按实测姿态描述（"你的姿态更接近 X 档常见范围"），避免以自报档位
  做硬判定。

## 3. 指标定义与视角可靠性

- 侧面（矢状面）可靠项：hip_flexion、knee_flexion、trunk_lean。两点限制：转弯中
  身体朝向相机旋转时 2D 投影会失真，建议按帧估计视角后再取值（二期）；坡面坡度
  直接进入 trunk_lean 的表观读数（垂直于 20° 坡面站直，相对竖直已有约 20° 倾角），
  相机不水平引入同类系统偏差（report.assumptions 已声明未做倾斜校正）。
- 正面/背面可靠项：knee_valgus、shoulder_hip_align 仅在此视角有意义，侧面下退化
  为噪声。（主会话复核：skibot 已按 METRICS 注册表的适用视角做报告门控，
  视角含糊（ambiguous）时不出指标——此建议已满足；帧级视角分类留二期。）
- knee_valgus 的混淆（几何事实，高把握）：正面髋-膝-踝夹角同时包含屈曲深度投影
  与真实内外翻。advanced 带 [94,153] 与 knee_flexion 带 [97,153] 几乎重合，说明该
  指标在竞技者身上主要由屈曲深度贡献——竞技者并不存在 30~80° 的解剖性内扣。
  若要做内扣筛查，可只在伸腿相（滑行/换弯直立帧）统计，或改做左右不对称比较。
  改名前，报告不得把"角度小于 180°"直接解读为内扣错误。
- 命名与解剖学距离：躯干-大腿夹角在几何上等于 180° − 躯干前倾 − 大腿前倾，
  同一夹角可由不同姿态组合拼出。五项指标是图像平面姿态描述量，不严格等于解剖学
  关节角，文档与报告中应写明，避免与生物力学文献数值直接互比。
- shoulder_hip_align 的测量噪声：肩线、髋线各由两个关键点连成，2D 姿态估计在这些
  端点的抖动常超过 5°，advanced 带下沿 4° 处在噪声内，此指标对档位判读力最弱。

## 4. 报告文案与判定逻辑

- pct_in_range（主会话复核：实现在 skibot/reference.py，帧级落带率，属实）：
  全程帧级百分比把入弯、弯中、换弯混在一起，且帧间强自相关，"落带率 60% 对 40%"
  的差异用户无法解读。建议并列报告中位数与四分位距，并把用户中位标在带内百分位
  位置上；后续可按相位（如仅弯中帧）拆分落带率（二期，依赖弯相位划分）。
- 对照档位：advanced 带对大众用户应作为参照系展示，标注"世界杯竞技者姿态范围，
  非大众目标"。自报中级者对竞技带 4~60% 的落带率反映的是人群差异，写成得分或
  达标率会误导。
- "参考值未校准"水印在 novice/intermediate 数值经真人教练确认前保留，做法正确。
- 教练示范段带率高于爱好者段，方向上支持指标系统有效；样本只有 3 段，属于合理性
  信号，够不上验证，文案不应写"已验证"。

## 5. 高把握结论汇总（供直接落地）

1. 五项参考区间随水平单调移动，方向见 2.1 节表；建议区间见 2.2 节表，落地时注明
   "原理推断值，待真人教练确认"。
2. knee_valgus 更名或降级为描述统计，停止"小于 180° 即内扣"式解读；其 advanced 带
   与膝弯带几乎重合是屈曲投影混淆的直接证据。
3. 指标按视角开关：正面膝角、肩髋对齐只在正面/背面帧计算；屈髋、膝弯、躯干前倾
   只在侧面帧计算。（已满足，见第 3 节复核。）
4. 报告并列"落带率 + 中位数 + 带内百分位"；advanced 带对大众用户只作参照系展示。
5. trunk_lean 报告固定提示坡度与相机水平带来的系统偏差。（report.assumptions 已有，
   见第 3 节复核。）
6. 本评审中把握最高的部分是方向性与单调性，可直接采用；所有精确角度数值（含本文
   建议值）无公开教学文献支持，属原理推断，待真人教练或按档位本地采数校准。

—— 三条最重要的评审发现 ——

1. knee_valgus 存在投影混淆（高把握）：advanced 带与 knee_flexion 带几乎重合，
   说明该正面髋-膝-踝夹角主要由屈曲深度贡献而非真实解剖性内扣，向大众用户报
   "内扣错误"会误导，应更名或降级为描述统计；该指标与肩髋对齐仅在正面/背面
   视角下有效。
2. 单调方向可高把握确认，精确数值只能中低把握：五项区间随水平单调移动，
   建议区间已给出并验证单调性与大众实测相容性；但所有精确角度数值无公开文献
   依据，属原理推断，待真人教练确认。
3. 精确数值落地谨慎：novice/intermediate 现行占位值与建议区间差异在占位值粗误差
   内，主会话决定参考值表维持现值不动、建议留档，避免把原理推断值当成更高信度
   的数值写入。
