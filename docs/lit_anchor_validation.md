# 文献锚点验收报告（issue 07，实拍前门）

日期：2026-10-26。结论：**不通过**——弯末髋、膝与内侧膝角度未全部落在
Bon et al. 2021 的均值 ±2SD 内；排查结论：不是指标定义或公式错误，主因是
现有素材不是平行弯（是鹤弯/标枪弯类练习动作）叠加单目提升的深度不确定性。
回炉路径见文末；实地采集（issue 08）前按此执行。

## 文献锚点

Bon I, Očić M, Cigrovski V, Rupčić T, Knjaz D. *What Are Kinematic and Kinetic
Differences between Short and Parallel Turn in Alpine Skiing?* Int J Environ
Res Public Health 2021;18(6):3029（MDPI/PMC 双源核对全文）。9 名男性滑雪教练
（33.4±8.6 岁），约 20° 坡，SL 板，Xsens MVN Link 17-IMU 240Hz；每人每弯型
12 弯、共 90 弯/弯型入分析。**PT = 平行式转弯，ST = 短转弯**（两种技术，
非测量定义——仓库此前把 "141.5/148.7°（PT/ST）" 理解为两种测量法是误读，
实为 PT 下左转弯/右转弯两组）。

- 弯末时刻（原文）：重心最低点、外板即将卸压前的一瞬。
- 角度口径：原文明确 "180° = knee and hip fully extended"；膝角为髋-膝-踝
  夹角。髋角原文只写 "angle of the right/left hip flexion"（Xsens 骨盆-大腿
  关节角），**未写肩-髋-膝**——docs/lit_angle_values.md 的"肩-髋-膝（髋）"
  是仓库推断，本报告按此口径对照并在判定中标注其不确定性。
- SD 是弯级变异（n=90 弯），±2SD 容差按弯级变异理解。

对比采用本管线中与该口径对应的三点夹角辅助量（`knee_interior_3pt`、
`hip_flexion_3pt`，180°=伸直，`metrics3d._frame_series` 同源公式逐侧计算）。
注意：ADR-0001 §6 冻结条款限定辅助量"只作教练对照，不参与判断"——本验收
是票面（issue 07）指定的例外场景，正式采用前需给 §6 补一行修订（见
「遗留事项」）。

## 排查结论（不通过的三个原因，按贡献排序）

1. **素材不是平行弯（主因）**。三段都是教练示范的练习动作：鹤弯/半幅鹤弯
   （内腿态特殊）、标枪弯（内腿抬起交叉）。即便用无深度参与的 2D 像素角
   （侧视下 ≈ 真实矢状角），弯间散布也有 ±27~37°，而 Bon 的弯级 SD 只有
   ±3.5~6.2°（90 个同技术弯的受控变异）。动作形态本身与文献锚点不同型。
2. **单目深度不确定性**。侧视机位下深度不可观，MotionBERT 按先验补 z；
   稳定帧上三维角与 2D 投影角差 14~21°（膝），超过 ±2SD 带数倍。x-y 投影
   一致性检查（相对位移误差为身高 2~5%）证明这不是输入或映射错误，而是
   深度先验的固有不确定性——这正是 spec 把「多机位真值」（issue 08/09）
   排在文献锚点之后要量化的东西。
3. **局部垃圾帧**。部分弯出现解剖不可能值（膝夹角 13~16°，骨穿透），来自
   检测/提升在遮挡与极端动作上的失败，已由 40° 护栏整弯剔除并计数。

**定义与公式排查为阴性**：Bon 六组 mean/SD 与左右转归属经原文 Table 1 核对
（左转弯外侧腿为右腿，由原文地面反作用力列 Max_F_R_LT≫Max_F_L_LT 独立证
实）；内外侧映射链（侧倾符号 → 弯向 → 外/内腿）逐环核对无误，且冠状前倾
"向左倾为正" 的符号契约已补测试钉住（`tests/test_metrics3d.py`）；弯末帧
语义与相位切分定义一致（半开区间端点，过零即换刃）。

## 排查中修掉的管线缺陷（本次排查的副产品）

`skibot/skeleton.py` 的 trc 别名表此前只有 12 个映射（挂着 TODO_VALIDATE）：
肘、腕、头顶、颈、髋中与十个脚点在真实 trc 里存在却被丢成 NaN，MotionBERT
的 17 个输入通道有 4 个恒为零。本次已按真实 trc 表头（22 marker）补全并加
测试；修复后模型输入解剖完整，锚点数值随之移动但判定方向不变。

## 回炉路径（重过此门的前提）

1. **换真正的平行弯素材**：`datasets/recreational_ski/archive.txt` 已登记三
   条示范级平行弯（BV1644y1o72G 动感小弯 95s、BV1qM4y187hr Interski 大弯
   281s、BV1yk4y177rL Interski 小弯 364s；原片已删需重下）。练习动作素材
   不再用于本门。
2. **先量化深度误差再重试单目门**：±2SD 容差 ±3.5~6°，而稳定帧单目三维角
   的不确定性就有 14~21°——素材换对了也可能过不了。按 spec 顺序先做
   issue 08（实地多机位采集）与 09（多机位真值验收），拿到逐帧角度误差上
   界后，判断单目管线是否可能过此门、或本门改用多机位口径执行。
3. 门脚本保留双采样（弯末/apex）与解剖护栏；护栏剔除数进报告。

## 遗留事项

- ADR-0001 §6 需补一行修订：辅助量在 issue 07 这类「与外部文献三点夹角对
  表」场景中作为验收口径（六项 JCS 主指标与动捕文献不可直接比）。已在本报
  告与 issue 07 记录，待睿君确认后落 ADR。
- 髋角口径差：Bon 是 Xsens 骨盆-大腿关节角，我们是肩-髋-膝三点夹角，两者
  相差躯干前倾分量；外髋格的判定对口径选择敏感（换口径可挪动 5~15°）。
- 相位覆盖薄：鹤弯类素材的冠状侧倾幅值小（p50 7°，贴近 6° 切弯门槛），
  有效弯少（n=5）。平行弯素材上预期显著改善。
