# ADR-0001：三维指标定义与坐标约定

- 状态：Accepted（2026-10-23）
- 决策者：睿君（产品负责人）；Claude Code 起草
- 关联：`.scratch/phase-2/spec.md`「指标基准」「决策记录」；任务票 01、02、03、04、08、10、12
- 冻结范围：六项主指标的定义、关节点、参考系、零点、符号与左右侧规则。
  本 ADR 接受后，改定义等于重标真值：必须新开 ADR，并重跑三层验证与参考带。

## 1. 背景

一期的五项指标是图像平面上的投影角。固定机位下，滑行者与相机的方位角、仰角、
距离全程在变，同一个动作换个机位读数就变。EPFL 116 个 clip 的髋部横向位置在
标注帧间跨度中位 0.29 个画面宽，只有 11 个 clip 基本跟住人——竞速素材本身就不是
恒定机位。二维角度不能当身体角度用。

二期把指标迁到三维骨架坐标：角度在骨架自身坐标中计算，相机方位不再进入读数；
躯干前倾以重力为零基准。规格已经定了方向，本 ADR 冻结规格留给实现层的几处选择：
近端段、关节点、符号、重力与坡度的取得方式。

## 2. 决定摘要

| 指标 | 平面 | 参考系 | 零点 | 正方向 | 相位聚合 | 主要关节点（Halpe-26） |
|---|---|---|---|---|---|---|
| `hip_flexion` 屈髋角 | 矢状 | 体固（躯干–股骨） | 躯干轴与股骨共线 = 180° | 角度变小 = 屈髋增加 | 是 | 5/6、11/12、13/14 |
| `knee_flexion` 膝弯曲角 | 矢状 | 体固（股骨–胫骨） | 完全伸直 = 0° | 屈曲量增加 | 是 | 11/12、13/14、15/16 |
| `trunk_lean` 躯干前倾 | 矢状 + 冠状 | 重力；坡面为派生 | 躯干轴与重力轴共线 = 0° | 前倾 / 向左侧倾 | 只聚合矢状分量 | 5/6、11/12 |
| `knee_abduction` 膝内外翻 | 冠状 | 体固（JCS 外展） | 胫骨长轴在股骨屈伸平面内 = 0° | 膝向中线（内扣方向） | 否，全程 | 11/12、13/14、15/16 |
| `hip_shoulder_separation` 肩髋横断面 | 横断 | 体固（法向 = 躯干轴） | 肩线投影与髋线投影对齐 = 0° | 左肩向前 | 否，全程 | 5/6、11/12 |

辅助量（`hip_flexion_3pt`、`knee_interior_3pt`）只给教练对照，不进参考带、
不进相位聚合、不作判断依据。

## 3. 骨架契约

### 3.1 关节点

输入为 Halpe-26，26 个关节。指标只依赖下列点：

- 5/6：左/右肩
- 11/12：左/右髋
- 13/14：左/右膝
- 15/16：左/右踝

20–25（大趾、小趾、脚跟）不进入六项定义。骨架契约仍要保留它们：动画要画脚，
质量检查与后续验证也可能用。17–19（head、neck、hip 根点）不进入定义；躯干与
骨盆的中点一律由左右对称点求平均，避免依赖模型自带的根点估计。

### 3.2 坐标与重力

- root-relative：原点 = 左右髋中点 `mid_hip`，不含世界轨迹、绝对位置或速度。
- 轴：`+x` = 解剖右侧，`+y` = 重力反方向（上），`+z` = 解剖前方；右手系。
- 左右侧按解剖侧标记，适配器不得镜像骨架。模型或输入镜像时，适配器负责纠正。
- 长度单位任意；角度指标尺度不变。角度输出单位为度。
- 每个关节带 [0,1] 置信度/可见性；缺测语义见任务票 03/04。
- 重力：契约要求适配器把骨架对齐到上述坐标系，`gravity_up = (0, 1, 0)`。
  若适配器只能输出相机坐标，必须在同一契约里给出逐帧重力向量；指标用传入的
  向量，不把 `+y` 写死。MotionBERT 适配器的重力来源见 §5.1。

### 3.3 记号

```text
unit(v)      = v / |v|
clip(x,a,b)  = min(max(x,a),b)
mid_sh       = (L_SHOULDER + R_SHOULDER) / 2
mid_hip      = (L_HIP + R_HIP) / 2
u_t          = unit(mid_sh - mid_hip)          # 躯干向上轴
s            = L_SHOULDER - R_SHOULDER         # 肩线，指向受试者左侧
h            = L_HIP - R_HIP                   # 髋线，指向受试者左侧
s_body       = unit(s - (s · u_t) u_t)         # 肩线在躯干横断面内的投影
a            = unit(u_t × s_body)              # 身体前向轴
g_up         = (0, 1, 0)                       # 契约重力反方向
```

退化条件（向量长度趋零、投影为零）一律返回 `NaN`，不猜值。

## 4. 参考系与零点

| 参考系 | 用在哪 | 零点的意思 |
|---|---|---|
| 体固 | 屈髋、膝弯、膝内外翻、肩髋横断面、肩髋冠状面 | 两个身体节段/线段共线或平行 |
| 重力 | 躯干前倾的矢状分量、冠状分量、总倾角 | 躯干轴与重力轴共线 |
| 坡面 | 躯干前倾的坡面法向版本 `slope_normal` | 躯干轴与坡面法线共线 |
| 相机/世界 | 不进六项指标；只用于动画显示与离线验证 | — |

重力版本的躯干前倾是默认口径。坡面法向版本需要坡度角 β；β 缺失时该项为
`null` 并带原因，不用 0 代替。

## 5. 六项指标

### 5.1 重力与坡度怎么来

重力有两个来源，按优先级：

1. **离线真值**：多机位标定的地面控制点给出重力方向。精度最高，只用于验证。
2. **运行时**：适配器输出的规范化骨架，或水平相机假设下的图像竖直方向。
   水平相机假设要求拍摄时相机 roll ≤ 1°、pitch ≤ 3°，采集协议记录水平仪读数；
   上传视频没有这项记录时，适配器必须给出它采用的重力来源。

运行时重力是否可信，由多机位验收回答（issue 09 的逐帧角度误差与跨机位一致性）。
验收前，报告给躯干前倾标注重力来源；验收不通过时该项不出数，不给 0。

坡度 β 由现场手机 IMU 倾角仪在滑行段测得（睿君 2026-10-23 决定）。采集记录
同时写坡度和滚落线相对拍摄方向的方位。β 是沿滚落线的坡角；投到受试者矢状面
的带符号分量为：

```text
β_sag = β · cos(φ_fall - φ_facing)      # 滚落线在身体前方为正，后方为负
```

直放下行时 `β_sag = β`。用户上传的视频没有 β，`slope_normal` 为 `null`
并注明「坡度未提供」。

### 5.2 `hip_flexion` 屈髋角

- 参考系：体固。近端段是躯干轴（下背–大腿），不是 ISB 骨盆–股骨。
- 关节点：5/6、11/12、13/14，取 `select_side` 选中的一侧。
- 定义：

```text
f   = unit(knee - hip)                 # 股骨远端方向
θ   = arccos(clip(u_t · f, -1, 1))     # 度
```

- 零点与符号：180° = 躯干轴与股骨共线（直立/伸直）；屈髋增加时 θ 变小。
  与二维 `hip_flexion`、Bon et al. 2021 的髋角同口径（180° = 伸直），可直接对照。
- 近端段取舍：Halpe-26 没有 ASIS/PSIS，骨盆朝向不可识别；骨盆–股骨 JCS 只能靠
  髋线 + 躯干轴近似，算出来的几何量与下背–大腿几乎相同，却会让人误以为它是
  ISB 口径。因此主指标明确用下背–大腿，报告与参考带都标注近端段。
- 辅助量 `hip_flexion_3pt`：同侧肩（5 或 6）–髋–膝三点夹角，同样 180° = 伸直。
  它与主指标不可互换：主指标用两侧肩中点构成的躯干轴，对肩带旋转不敏感；
  辅助量用单侧肩，是教练熟悉的说法。
- 限制：胸椎屈曲会进入躯干轴，被算成屈髋。报告标注近端段后由教练判读。

### 5.3 `knee_flexion` 膝弯曲角

- 参考系：体固（Grood–Suntay 屈伸）。
- 关节点：11/12、13/14、15/16，取 `select_side` 选中的一侧。
- 定义：

```text
v_t = unit(hip - knee)                  # 膝指向髋，近端
v_s = unit(ankle - knee)                # 膝指向踝，远端
θ_flex  = 180 - arccos(clip(v_t · v_s, -1, 1))
θ_inter = 180 - θ_flex                  # 教练惯用的膝夹角
```

向量方向是定义的一部分：`v_t` 必须从膝指向髋。若改成膝指向髋的反向，
完全伸直会读成 180° 而不是 0°。

- 零点与符号：0° = 完全伸直；θ_flex 增加 = 屈膝增加。
- 报告口径：三维列用 `θ_flex`（0° = 伸直）；二维回归列用 `θ_inter`（180° = 伸直）。
  两列都写明零点，禁止把两个数直接相减。
- 与二维的换算：`θ_flex = 180 - θ_2d_interior`。近平面条件下，这个换算是
  issue 04 的等价性测试。
- 限制：只有髋膝踝三点，不含股骨/胫骨扭转。深蹲相位的二维投影放大误差在
  三维口径下应显著减小，但 issue 09 验证通过前，报告保留深蹲 caveat。

### 5.4 `trunk_lean` 躯干前倾

- 参考系：重力为主，坡面为派生。
- 关节点：5/6、11/12。
- 定义：

```text
u_t   = unit(mid_sh - mid_hip)
g_up  = (0, 1, 0)                       # 或适配器给出的逐帧重力反方向
s     = L_SHOULDER - R_SHOULDER
s_body = unit(s - (s · u_t) u_t)
a     = unit(u_t × s_body)              # 身体前向

θ_sag   = atan2(-(g_up · a),      g_up · u_t)  # 矢状分量，正 = 前倾
θ_frt   = atan2(-(g_up · s_body), g_up · u_t)  # 冠状分量，正 = 向受试者左侧倾
θ_total = arccos(clip(u_t · g_up, -1, 1))
θ_slope = θ_sag - β_sag                       # 坡面法向版，β 缺失时为 null
```

- 零点：`θ_sag = θ_frt = 0` = 躯干轴与重力轴共线；`θ_slope = 0` = 躯干轴与
  坡面法线共线。
- 符号：正 = 前倾 / 向左侧倾 / 相对坡面法线前倾。
- 输出结构：

```text
trunk_lean = {
  sagittal_deg:      float | null,
  frontal_deg:       float | null,
  total_deg:         float | null,
  slope_normal_deg:  float | null,
  gravity_source:    "calibrated" | "adapter" | "image_vertical",
  slope_source:      "imu" | "none",
}
```

- 相位聚合：只聚合 `sagittal_deg`。`frontal_deg` 进全程统计；`slope_normal_deg`
  作为矢状分量的派生伴随量，有 β 时一并输出。
- 限制：`a` 由肩线与躯干轴叉乘得到，肩线不可靠时前向轴漂移；胸椎侧弯进入
  `frontal_deg`。坡面版只给矢状投影，横穿时的横向坡度分量本版不报。

### 5.5 `knee_abduction` 膝内外翻（原 `knee_valgus`）

- 参考系：体固，Grood–Suntay 外展。命名用中性的 JCS 术语；旧的
  `knee_valgus` 在任务票 02 里迁移。
- 关节点：11/12、13/14、15/16，左右腿分别计算。
- 定义：

```text
h   = L_HIP - R_HIP                     # 指向受试者左侧
f   = unit(knee - hip)                  # 股骨远端
e1  = unit(h - (h · f) f)               # 股骨内外侧轴近似（来自髋线）
e3  = unit(ankle - knee)                # 胫骨长轴，远端方向
β'  = arccos(clip(e1 · e3, -1, 1))
β_right = β' - 90
β_left  = 90 - β'
```

- 零点与符号：0° = 胫骨长轴落在股骨屈伸平面内；β > 0 = 膝向中线移动
  （俗称内扣方向）；β < 0 = 膝远离中线（外翻/varus 方向）。
  `β_left = 90 - β'` 就是规格里的「左腿反向」，它把两侧的符号统一到
  「正 = 内扣方向」。
- 报告口径：

```text
knee_abduction = {
  primary_deg: float | null,   # max(left, right)，更偏内扣的一侧
  left_deg:    float | null,
  right_deg:   float | null,
  side:        "left" | "right" | null,
}
```

  参考带建在 `primary_deg` 上；报告同时给两侧值，用户能看出是哪条腿。
- 聚合：全程。额状面没有经过验证的相位定义，不做相位拆分。
- 限制，写进报告与验证报告：
  - `e1` 是髋线近似，缺少股骨内外上髁。髋关节内/外旋、骨盆旋转会泄漏进 β。
  - 这个量是描述统计，不是「是否有内扣风险」的临床判断。KVA 2G/3G 只作对照，
    并注明投影平面。
  - 髋旋转泄漏的量级由 issue 09 的多机位验收回答；若超出误差预算，另开 ADR
    修改定义，重标真值。

### 5.6 `hip_shoulder_separation` 肩髋横断面分离（H-Ssep）

- 参考系：体固，横断面法向 = 躯干轴。
- 关节点：5/6、11/12。
- 定义：

```text
u    = u_t
h_p  = h - (h · u) u
s_p  = s - (s · u) u
ψ    = atan2((h_p × s_p) · u, h_p · s_p)
```

- 零点与符号：0° = 肩线投影与髋线投影对齐；正 = 左肩相对左髋向前
  （在 `+x` 右、`+y` 上、`+z` 前的契约坐标里由叉乘定号）。参考带建在
  `|ψ|` 上，报告保留符号。
- 聚合：全程。
- 限制：躯干接近水平时投影退化；肩线/髋线关键点误差直接进入 ψ；没有脊柱
  标记，无法区分胸椎旋转与肩带旋转。

### 5.7 `thoraco_pelvic_obliquity` 肩髋冠状面倾斜

- 参考系：体固，冠状面法向 = 身体前向轴。
- 关节点：5/6、11/12。
- 定义：

```text
a    = unit(u_t × s_body)               # 前向轴，与 5.4 相同
s_f  = s - (s · a) a
h_f  = h - (h · a) a
φ    = atan2((s_f × h_f) · a, s_f · h_f)
```

- 零点与符号：0° = 肩线投影与髋线投影在冠状面内平行；正 = 左肩高于右肩。
  参考带建在 `|φ|` 上，报告保留符号。
- 聚合：全程。
- 限制：与 H-Ssep 共享关键点误差；肩带旋转大时前向轴漂移；两项不合成一个数。

## 6. 辅助量

```text
hip_flexion_3pt  = 同侧（肩, 髋, 膝）三点夹角，180° = 伸直
knee_interior_3pt = 同侧（髋, 膝, 踝）三点夹角，180° = 伸直
```

辅助量只用于报告里的教练对照，不参与判断、参考带、相位聚合与可比性判定。

## 7. 侧别与缺测

- 侧别：沿用一期的 `select_side`，三维版本按契约置信度选高的一侧；二维的
  「近侧肢体更可信」在三维里不成立，判断依据换成置信度。
- `knee_abduction` 两侧都算，主值取更偏内扣的一侧。
- 缺测：任一必需关节的置信度低于阈值（暂定 0.3，issue 04 用合成与真实素材
  定稿）时，该帧该指标为 `NaN`。指标层不跨缺测插值；适配器若做时域平滑，
  必须写进数据来源说明。
- 报告层：相位数据不足时为 `null` 并带原因，不写 0。

## 8. 与二维口径的换算

| 指标 | 二维口径 | 三维口径 | 能否直接比 |
|---|---|---|---|
| 屈髋 | 肩-髋-膝夹角，180° = 伸直 | 躯干轴-股骨，180° = 伸直 | 近平面可比；严格对照用 `hip_flexion_3pt` |
| 膝弯 | 髋-膝-踝夹角，180° = 伸直 | 屈曲量，0° = 伸直 | `θ_flex = 180 - θ_2d`，换算后比 |
| 躯干前倾 | 图像平面内与竖直的偏角 | 重力参考的矢状/冠状分量 | 只在相机垂直矢状面且水平时可比 |
| 膝内外翻 | 正面髋-膝-踝夹角 | JCS 外展，0° = 无内外翻 | 不可直接比，KVA 只作投影对照 |
| 肩髋 | 图像平面内肩线-髋线夹角 | 横断面 ψ + 冠状面 φ | 二维是一个混合角，不可直接拆 |

过渡期报告并列二维与三维两列，各自写明参考系、零点、符号与 marker 方案。

## 9. 验收用例

定义的正确性用合成骨架回答，测试落在 issue 04：

1. 直立骨架：`hip_flexion = 180`、`knee_flexion = 0`、`trunk_lean` 各分量 0、
   `knee_abduction = 0`、H-Ssep 0、obliquity 0。
2. 矢状面屈膝 90°：`knee_flexion = 90`、`knee_interior = 90`、膝内外翻 0。
3. 左/右腿分别做内扣：两侧 β 都为正；做外翻：两侧都为负。
4. 左肩向前转：ψ 为正；左肩高于右肩：φ 为正。
5. 整个骨架与重力向量一起绕重力轴旋转：六项指标不变。
6. 骨架不动、重力向量倾斜：只有 `trunk_lean` 变化，体固指标不变。
7. 正交投影到图像平面：三维 `hip_flexion` 与二维口径一致，`knee_interior`
   与二维膝弯一致，误差在 0.1° 内。
8. 缺一个必需关节、或线段共线：返回 `NaN`，不抛异常。

## 10. 未决与待验证

- 运行时重力来源：水平相机假设与模型规范化输出哪个更稳，由 issue 09 的重力
  对齐测试回答。验收前报告标注来源；不可信时躯干前倾不出数。
- 置信度阈值 0.3：issue 04 暂保留。三维指标层只消费 conf ≥ 0.3 的关节；
  阈值要等 issue 05 的真实适配器与 issue 09 的多机位素材才能定稿。
- 髋旋转泄漏进 `knee_abduction` 的量级：issue 09 量化。超出误差预算就改定义，
  新开 ADR。
- 近端段只用躯干轴：若多机位验证显示与 ISB 骨盆–股骨的系统差超过 5°，
  在报告里并列 ISB 近似值，但主口径不改，除非新开 ADR。
- 脚部点（20–25）不进入六项定义；动画与质量统计保留。

## 11. 决策记录

- 2026-10-23，睿君：屈髋角主口径用下背–大腿（躯干轴），不用骨盆–股骨。
  理由：Halpe-26 无 ASIS/PSIS；与 Bon et al. 及滑雪文献可比。
- 2026-10-23，睿君：坡度 β 用现场手机 IMU 倾角仪测量。
- 2026-10-23，起草人：躯干/骨盆中点用左右对称点平均，不用 Halpe-26 的
  neck/hip 根点。理由：左右点对称，不依赖模型自带根点的估计。
- 2026-10-23，起草人：膝内外翻主值取更偏内扣的一侧，两侧值都报。
