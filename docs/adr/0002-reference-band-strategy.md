# ADR-0002：三维参考带的生成口径与过渡策略

- 状态：Accepted（2026-10-23）
- 决策者：睿君（产品负责人）；Claude Code 起草
- 关联：`.scratch/phase-2/spec.md`「参考区间」「验证与采集」；ADR-0001；
  任务票 02、09、10、11、12
- 冻结范围：三维参考带的数据来源、带宽规则、档位外推方式、过渡期报告口径。
  具体数值在 issue 12 生成，不在本 ADR 冻结。

## 1. 背景

一期参考带是全程、二维、不分相位的中位数区间：
`reference_values.toml` 里 advanced 档来自 EPFL 竞技者人工标注的 p25~p75，
novice/intermediate 是教学定性描述转译的占位值。两件事同时变了：

1. 指标迁到三维，部分指标的零点与量纲变了（膝弯从 180°=伸直变成 0°=伸直，
   膝内外翻从二维夹角变成 JCS 外展）。
2. 报告按入弯/控制/出弯分相位，参考带也要有相位维度。

三维真值只有自采多机位一份，样本量撑不起任何一档的分布。EPFL 有 158 个 clip、
1982 帧人工标注，是现有最大的竞技素材；但它是二维标注，没有三维真值。

## 2. 决定

### 2.1 advanced 档：验证过的三维管线跑 EPFL

- 用通过三层验证（文献锚点 → 多机位真值 → 现有素材物理一致性）的三维管线，
  在 EPFL 素材上跑出三维骨架，按相位取 p25~p75，作为 advanced 档的带。
- 这条带是「三维管线在竞技素材上的分布」，不是「三维真值的分布」。报告与
  参考值文件都这么标注，避免把管线误差当成运动学分布。
- 管线误差上界来自 issue 09 的多机位验收：六项指标逐项给中位与 p90 误差。
  验收未通过时，不出 advanced 三维带。
- 带宽规则：设某指标某相位的带为 `[lo, hi]`，中位为 `m`，验收得到的 p90
  绝对误差为 `e90`。发布带必须满足每一侧到中位的距离不小于 `e90`：

```text
lo' = m - max(m - lo, e90)
hi' = m + max(hi - m, e90)
```

  原始 p25~p75 比误差区间窄时，按此对称加宽。带宽窄于测量误差的带会制造
  虚假精度，不允许发布。
- 误差上界写进带的说明字段；报告页展示带时同时展示这句话。

### 2.2 novice/intermediate 档：相位形状外推，数值仍为占位

这两档没有分相位的三维数据。做法是把 advanced 实测的相位相对形状套到现有
占位带上，并明确标注「档位数值未校准、二维口径外推」：

```text
δ_p = m_adv,p - m_adv          # 某相位的偏移
m_ph,p = m_ph + δ_p            # 套到占位全程中位
lo_ph,p = lo_ph + δ_p
hi_ph,p = hi_ph + δ_p
```

用加性偏移，不用比例：角度有物理零点，比例在零点附近没有意义。偏移在三维
口径上计算；占位带先换算到三维口径，再套偏移。

逐项换算：

| 指标 | 占位带怎么处理 | 备注 |
|---|---|---|
| `hip_flexion` | 直接沿用（180° = 伸直，口径相同） | 近端段从单侧肩改成躯干轴，报告标注 |
| `knee_flexion` | `[lo, hi] → [180-hi, 180-lo]` | 换算成 0° = 伸直的屈曲量后再套偏移 |
| `trunk_lean` 矢状 | 作为临时矢状带沿用 | 二维是图像平面总角，三维是重力分量，标注「外推」 |
| `trunk_lean` 坡面 | 无参考带 | 没有二维前身，等本地采数 |
| `knee_abduction` | 无参考带（`null`） | 二维夹角与 JCS 外展量纲不同，不能换算 |
| `hip_shoulder_separation` | 无参考带（`null`） | 旧的肩髋对齐是图像平面混合角，不能直接拆 |
| `thoraco_pelvic_obliquity` | 无参考带（`null`） | 没有二维前身 |

`null` 的带在报告里显示「无参考带（未校准）」，只给描述统计，不给判断。
这比拿一个不可比的旧带硬套更诚实。

### 2.3 过渡期报告并列二维与三维

- 报告保留二维列与旧带，新增三维列与新带。两列各自写明参考系、零点、符号、
  marker 方案，禁止跨列直接比较数值。
- 三维验证通过（issue 09）且对应带存在之前，二维列是默认判断依据，三维列
  标为实验口径，不给教学结论。
- 三维验证通过后，三维列成为默认依据；二维列保留作回归对照与外部效度参考，
  不删除。
- novice/intermediate 的「参考值未校准」水印继续存在，适用于二维与三维两列。
  真人教练或本地采数确认前，带内判断只作描述，不作对外结论。
- `schema` 升版；每个指标条目带 `basis: "2d" | "3d"`，相位对象带各自的
  中位数、落带率、带内百分位、有效帧数、判断与原因。

### 2.4 自采多机位素材只做验证

多机位自采素材（issue 08）样本量小、覆盖条件有限，只用于：
逐帧角度误差、跨机位一致性、重力对齐、相位切分标注验收。
它不参与任何一档的参考带统计。

### 2.5 不在三维真值上重算

理由：

1. 自采样本只有几次采集、少量滑手，撑不起分档或分相位的分布。
2. Ski-Pose PTZ 的外部三维真值尚未获批；即便获批，它是竞技素材，仍不是
   大众档位的分布。
3. 验证过的管线在 EPFL 上的分布有明确的误差上界；带加宽规则把这个上界
   转成可读的宽度。这个口径可以复现、可以复核。
4. 用少量三维真值重算会得到一个窄而不可推广的带，比管线分布更容易误导。

## 3. 后果

- advanced 三维带可能比二维带更宽。这是测量误差进入口径的结果，不为了好看
  收窄。
- 膝内外翻、肩髋冠状面在 novice/intermediate 档暂时没有三维带。报告显示
  `null` 与原因，用户看到的是「还没校准」，不是「正常」。
- 相位形状从 advanced 外推到 novice/intermediate 的前提是「水平间相位形状
  一致」。这个前提未经证明，写进报告假设与规格风险；真人教练或本地采数
  确认前不作对外结论。
- 指标定义一旦改动（新 ADR），已发布的带全部作废，必须重跑管线与验收。

## 4. 落地顺序

1. issue 04/05：三维指标与 MotionBERT 管线跑通。
2. issue 09：多机位验收，给出逐项 `e90` 与重力对齐结论。
3. issue 10/11：相位切分与人工标注验收。
4. issue 12：按本 ADR 生成带、写说明、升版报告 schema；二维列保留。
5. issue 18：前后对比只比两侧都有有效相位数据的项。

存储格式（扩展现有 TOML 还是新增三维文件）由 issue 02/12 决定；本 ADR 冻结
的是内容规则：来源、相位维度、误差上界、加宽规则、`null` 语义。

## 5. 未决

- 每个相位的样本量是否足够出 p25~p75：issue 12 在生成时统计有效帧与弯数，
  不足的相位标 `null`，不插值。
- EPFL 的三维管线输出是否需要按机位方位角分层：验收按方位角分层（issue 09）；
  带的生成是否分层由 issue 12 看样本量决定，样本不足时用合并分布并注明。
- 真人教练对 novice/intermediate 数值的确认时间未定；确认前水印不摘。

## 6. 决策记录

- 2026-10-23，起草人：advanced 三维带用验证过的管线跑 EPFL，不在自采三维
  真值上重算；带宽按验收 `e90` 加宽。理由见 §2.5。
- 2026-10-23，起草人：novice/intermediate 的相位形状用加性偏移从 advanced
  外推；量纲不同的指标（膝内外翻、肩髋两项）三维带为 `null`。
- 2026-10-23，起草人：二维列不删除，三维验证通过前不作默认判断依据。
